测试报告推动着开发。一次带有完整日志的崩溃，和一次能进入游戏的运行同样有用。报告发布在 GitHub 的 **Game bring-up**（游戏适配）讨论区，每款游戏一个帖子，并会自动显示在本站的[兼容性页面](/compatibility)上。

<Callout title="即将推出：上传运行报告">
AnyPS5 即将在每次运行后，在游戏旁边写入运行报告 `anyps5-report.json`。[上传它](/report)，你的结果就会加入兼容性列表，无需填写任何表单。在新版本支持之前，请按下面的说明在讨论区发帖。
</Callout>

## 找到或新建帖子

1. 在[兼容性列表](/compatibility)中搜索你的游戏。它的页面上有一个 **Add a test report**（添加测试报告）按钮，会打开已有的帖子。
2. 如果游戏不在列表中，就新建一个[适配报告](https://github.com/boykopovar/AnyPS5/discussions/new?category=game-bring-up)。标题格式如 `Game Name (PPSA01234)`。

## 需要包含什么

表单会询问以下内容。知道的就填，其余留空即可。

- **Title ID 和内容版本**，不要只写游戏名。
- **AnyPS5 版本**：发布版本（例如 v0.1.3），或者提交以及在其之上应用的拉取请求。
- **你的系统**：CPU、操作系统、显卡和驱动版本。
- 游戏到达的**最远进度**：无法转换、在第一帧之前停止、Logo 或加载画面、菜单，或进入游戏。
- **显示了什么**以及**是什么导致停止**：错误信息、退出代码和输出的最后几行。

## 报告如何变成阶段

本站上的每款游戏都处于一个八级阶梯中的某个阶段，从 **Converts**（能转换）到 **Playable**（可游玩）。你报告中的最远进度决定了阶段，维护者也可以进一步调整。带有额外补丁的开发版本的结果会单独显示，以免夸大当前发布版本的实际能力。

<Callout title="游戏页面上有错误？">
每个游戏页面都有一个 **Suggest a correction**（建议修正）链接。人工整理的修正优先于自动报告。
</Callout>
