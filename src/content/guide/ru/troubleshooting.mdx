Когда что-то пока не поддерживается, AnyPS5 не пытается угадать, а останавливается с ошибкой и пишет причину. Сначала прочитайте последние строки вывода. Если в Windows игра была запущена без консоли, вывод сохраняется в `anyps5.log` рядом с исполняемым файлом.

## Ошибки и решения

| Что вы видите | Что делать |
|---|---|
| Игра перечисляет недостающие расширения процессора | Вашему процессору не хватает инструкций, нужных игре. См. [требования](/guide/requirements#processor). |
| Windows пишет, что приложение несовместимо (код выхода 216) | Игру сконвертировали для Linux. Сконвертируйте заново, выбрав **Windows**, или с `--windows`. |
| Ошибка 193 в Windows | В `libs/` лежит оригинальный `.prx` с PS5. Там место только библиотекам AnyPS5. |
| Ошибка 126 в Windows | Не хватает библиотеки. Используйте библиотеки из архива релиза — в нём есть нужные DLL. |
| `[gpu] open /dev/udmabuf: Permission denied` | Добавьте своего пользователя в группу `kvm` и перезайдите в систему. |
| Ошибка, связанная с `param.json` | Скопируйте `sce_sys/param.json` игры в `app0/sce_sys/`. |
| Ошибка чанка PlayGo при запуске | Задайте `APS5_PLAYGO_UNLISTED_CHUNKS`. См. [подготовку дампа](/guide/dump#known-problems-with-some-dumps). |
| `sceFontOpenFontSet` с `file=(none)` или пропавший текст | Добавьте [системные шрифты](/guide/run#system-fonts). |
| `replace guest placeholder with resident direct memory` | Windows не хватило выделяемой памяти. Увеличьте файл подкачки. |
| `sceSystemServiceLoadExec: execv failed: Permission denied` | Выполните `chmod +x` для каждого исполняемого файла, который записал конвертер. |
| `SDL_GetWindowDisplayIndex failed` | Во время запуска игры монитор был в спящем режиме. Разбудите его и запустите снова. |
| Вылет в `nvgpucomp64.dll` | Известная ошибка драйвера NVIDIA. Обновите драйвер. |
| Windows падает при поиске видеокарт | Возможно, установлен Mesa Dozen. Перед запуском игры выполните `$env:VK_LOADER_DRIVERS_DISABLE = '*dzn*'`, если только Dozen — не единственный ваш драйвер Vulkan. |
| Долгий чёрный экран при первом запуске | Компилируются шейдеры. Подождите — следующий запуск будет быстрее. |

## Если игра останавливается сама

Большинство игр натыкаются на что-то, что ещё не реализовано. Сообщение с `what()` или `terminate called` называет недостающую часть. Исправить это на своей стороне вы не сможете, но именно это и нужно разработчикам.

1. Найдите свою игру в [списке совместимости](/compatibility). Если остановка уже известна, там указан issue, в котором её отслеживают.
2. Проверьте на [странице загрузки](/download), не вышел ли новый релиз.
3. Если ваш результат новый, [сообщите о нём](/guide/report).

## Коды выхода

Релинкер завершается с кодом `0` при успехе, `1` при неверных аргументах и `2`, если конвертация не удалась (причина выводится).

В Linux код выхода игры `134` означает остановку на неподдерживаемой возможности или ошибке, а `139` — вылет. В Windows `0xc0000005` — это вылет, а `0xc0000409` — неподдерживаемая возможность.
