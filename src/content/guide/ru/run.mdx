## Запуск игры

<Tabs>
<Tab platform="linux">

Из папки с игрой:

```sh
./app.elf
```

У файлов, скачанных через браузер, пропадает флаг исполняемого файла. Если игра не запускается, выполните `chmod +x app.elf` (и то же самое для остальных исполняемых файлов, которые перечислил конвертер).

</Tab>
<Tab platform="windows">

Дважды щёлкните `app.exe` или запустите из PowerShell в папке с игрой:

```powershell
.\app.exe
```

Запускайте из обычного рабочего стола с выполненным входом, а не через SSH.

</Tab>
</Tabs>

<Callout title="Первый запуск — медленный">
При первом запуске AnyPS5 компилирует шейдеры игры под вашу видеокарту. До первого кадра может пройти несколько минут. Результаты сохраняются в `shader_cache/` рядом с исполняемым файлом, поэтому следующие запуски гораздо быстрее. Папку можно спокойно удалить.
</Callout>

## Управление

Геймпады, которые распознаёт SDL, работают сразу: DualSense, DualShock 4 и геймпады в стиле Xbox. Стики и аналоговые триггеры передаются как есть, тачпад DualSense работает, а геймпад можно подключить прямо во время игры.

Без геймпада действуют такие клавиши клавиатуры и мыши:

| PS5 | Клавиатура и мышь |
|---|---|
| Крест | Enter, пробел |
| Круг | C |
| Треугольник | I |
| Квадрат | Левая кнопка мыши |
| L1 / R1 | Q / E |
| L2 / R2 | R / правая кнопка мыши |
| L3 / R3 | Shift / Ctrl |
| Options | Esc |
| Крестовина | Стрелки |
| Левый стик | W A S D |
| Правый стик | T F G H или мышь после нажатия средней кнопки мыши или F7 |
| Тачпад | Backspace (левая половина), Tab (правая) |

**F11** переключает полноэкранный режим, а **F10** показывает оверлей производительности. Чтобы переназначить клавиши, создайте `anyps5-input.ini` рядом с исполняемым файлом; подробнее — в разделе [настройки управления](/docs/input-mapping).

## Дополнительные настройки

Задайте эти переменные окружения перед запуском игры.

| Переменная | Что делает |
|---|---|
| `ANYPS5_LANGUAGE` | Номер языка консоли. `1` — английский (США), по умолчанию; `18` — английский (Великобритания), `2` — французский, `4` — немецкий, `3` — испанский, `0` — японский. [Все языки](/docs/usage#console-language) |
| `ANYPS5_GPU` | Часть названия видеокарты, чтобы выбрать другую |
| `ANYPS5_PRESENT_MODE` | `mailbox` или `immediate`, чтобы отключить вертикальную синхронизацию |
| `ANYPS5_OVERLAY` | `1` показывает оверлей производительности с самого начала |

<Tabs>
<Tab platform="linux">

```sh
ANYPS5_LANGUAGE=18 ./app.elf
```

</Tab>
<Tab platform="windows">

```powershell
$env:ANYPS5_LANGUAGE = '18'
.\app.exe
```

</Tab>
</Tabs>

## Системные шрифты

Некоторые игры используют системные шрифты консоли и без них не показывают текст или останавливаются. Положите файлы шрифтов в папку `anyps5-fonts/` рядом с исполняемым файлом. Шрифты из дампа вашей консоли подходят под своими именами. Иначе в качестве замены подойдут бесплатные шрифты [Noto](https://github.com/notofonts/notofonts.github.io): `NotoSans-Regular.ttf` и его начертания, `NotoSansMono`, `NotoSansThai` и `NotoSansCJK`. Точные имена файлов — в [справке по использованию](/docs/usage#system-fonts).

## Сохранения

Сохранения хранятся в папке `_sd/` рядом с `app0/`. Чтобы перенести прогресс в другую копию игры, скопируйте `_sd/` и `_sd_mem/`.
