При конвертации исполняемый файл и модули игры переписываются в нативную программу для Linux или Windows, а рядом с ней кладутся системные библиотеки AnyPS5. Ваши файлы никуда не уходят с компьютера.

1. Откройте [веб-конвертер](/convert).
2. Выберите папку с дампом или перетащите один или несколько ZIP-файлов.
3. Выберите **Windows (.exe)** или **Linux (.elf)**.
4. Выберите, как сохранить результат:
   - **Download in memory** («Скачать из памяти») — для небольших игр, до 256 МиБ.
   - **Save ZIP to disk** («Сохранить ZIP на диск») — для больших игр. Нужен Chrome или Edge для компьютера.
   - **Save to folder** («Сохранить в папку») — записывает несжатую папку. Только для Linux и только одна игра за раз.
5. С процессором Intel отметьте **Convert AMD-specific instructions for Intel CPUs** («Преобразовать AMD-инструкции для процессоров Intel»).
6. Нажмите **Convert & save**.

В результате уже есть системные библиотеки и правильная структура папок. Перед запуском игры **распакуйте ZIP целиком**.

<Callout title="Много игр сразу">
Перетащите несколько ZIP-файлов, чтобы сконвертировать их в один пакет. Каждая игра получит свою пронумерованную папку.
</Callout>

## В командной строке

Нативный релинкер справляется с играми любого размера, и у него больше настроек. Скачайте `relinker` и архив библиотек для своей системы со [страницы загрузки](/download), переименуйте скачанный релинкер в `relinker` (или `relinker.exe`) и запустите его на исполняемом файле игры. Папка `sce_module/` игры должна лежать рядом с `eboot.bin`.

<Tabs>
<Tab platform="linux">

```sh
chmod +x relinker
./relinker app0/eboot.bin game/app.elf
unzip prx-linux-*.zip -d game/
```

</Tab>
<Tab platform="windows">

```powershell
.\relinker.exe --windows app0\eboot.bin game\app.exe
Expand-Archive prx-windows-*.zip -DestinationPath game
```

Без `--windows` на выходе получается файл для Linux, даже если его имя заканчивается на `.exe`, и Windows откажется его запускать.

</Tab>
</Tabs>

Архив библиотек распаковывается в папку `libs/`. Используйте архив, собранный для той же системы, что и игра.

Полезные параметры:

| Параметр | Когда нужен |
|---|---|
| `--to-intel` | Вы играете на процессоре Intel |
| `--module-dir <dir>` | Игра загружает модули из других папок, например `Media/Plugins` у Unity |
| `--registry` | Хотите заранее узнать, какие системные функции нужны игре |

Все параметры перечислены в [справке по использованию](/docs/usage#options).

## Разложите файлы

Релинкер выводит структуру, которую ожидает (`Arrange the files like this`). Выглядит она так:

```text
game/
    app.elf  or  app.exe     the converted executable
    libs/                    AnyPS5 system libraries
    app0/                    the game's original files
        eboot.bin            keep the original, games look for it
        sce_sys/param.json
        sce_module/          the converted modules (the relinker prints each one
                             as "Guest module:")
```

- Скопируйте остальное содержимое дампа в `app0/`, включая исходный `eboot.bin`.
- Кладите в `libs/` только библиотеки AnyPS5. Оригинальные файлы `.prx` с PS5 в `libs/` приводят к ошибке 193 в Windows.
- В Linux в `app0/` не должно быть символических ссылок. Используйте копии или жёсткие ссылки.
