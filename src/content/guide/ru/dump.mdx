AnyPS5 работает с файлами установленной игры, дамп которой вы сняли со своей консоли своими homebrew-инструментами. Проект не предоставляет дампер и не может помочь достать игры, которых у вас нет.

## Что должно быть в дампе

Конвертеру нужны файлы игры в **расшифрованном** виде:

```text
app0/
    eboot.bin          the game's executable, as a plain ELF file
    sce_module/        the game's own libraries
    sce_sys/
        param.json     the title ID and name
    ...                everything else the game ships with
```

- **Исполняемый файл должен быть обычным ELF-файлом.** Зашифрованные контейнеры SELF не принимаются. Если ваш дампер выдал расшифрованные контейнеры SELF, сначала распакуйте их скриптом `tools/unwrap_self.py` из репозитория AnyPS5.
- **Сохраните `sce_sys/`.** Многие игры читают `param.json` при запуске и без него не работают.
- **Сохраните остальные файлы игры.** Конвертер переписывает только исполняемый файл и модули, но во время работы игре нужны лежащие рядом файлы данных.

Веб-конвертеру можно отдать всю папку `app0` или её ZIP-архив. Большие файлы, кроме исполняемого файла и модулей, могут оставаться в архиве.

## Запишите версию контента

**Версия контента** (например, `01.004.000`) важна, когда вы делитесь результатами. Разные версии одной игры могут вести себя по-разному, а патчи для игр привязаны к конкретным байтам. Её можно найти в `sce_sys/param.json` в поле `contentVersion`.

## Известные проблемы с некоторыми дампами

<Callout title="Дампы, перепакованные для ampr_emu">
Если в `app0` есть `ampr_assets.index` и `ampr_assets-*.pak`, дамп перепаковали для ampr_emu, и части файлов в `app0` не хватает. Сначала распакуйте его командой `tools/ampr_pack.py unpack` из ampr_emu и скопируйте недостающие файлы обратно. Иначе игры на Unity остановятся при запуске.
</Callout>

<Callout title="Дампы без метаданных PlayGo">
Если в дампе нет ни `sce_sys/playgo-chunk.dat`, ни `sce_sys/playgo-scenario.json`, некоторые игры останавливаются при запуске с ошибкой чанка PlayGo. При запуске игры задайте `APS5_PLAYGO_UNLISTED_CHUNKS` значение `installed` или `absent`. Какое подойдёт, зависит от игры; известные случаи перечислены в [справке по использованию](/docs/usage#playgo-dumps-without-metadata).
</Callout>

<Callout title="Игры на Unity">
Игры на Unity хранят дополнительные модули в `Media/Modules` и `Media/Plugins`. Веб-конвертер справляется со стандартной структурой сам. С релинкером в командной строке добавьте `--module-dir Media/Modules --module-dir Media/Plugins`.
</Callout>
